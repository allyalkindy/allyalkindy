## 👨‍💻 About Me

I'm **Ally Mohammed Said**, a Full Stack Developer Intern at **Binary Flow Tech**, based in Dar es Salaam, Tanzania. I enjoy building practical, end-to-end applications — from web apps and mobile experiences to small ML-powered tools — and learning by shipping real projects.

- 🔭 Currently working on full-stack web and mobile applications at **Binary Flow Tech**
